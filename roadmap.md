# BabyFood Tracker — Roadmap

## Phase 1 — Fondations (done)
- [x] Design system (ivoire, beige, sauge, charbon; Fraunces + Plus Jakarta Sans)
- [x] Auth e-mail/mot de passe + Google, mot de passe oublié
- [x] Schéma : profiles, user_roles, families, family_members, babies + RLS
- [x] Onboarding + profils bébés (créer, modifier, supprimer, changer)
- [x] Navigation mobile (barre du bas + bouton flottant) et barre latérale desktop

## Phase 2 — Cœur
- [ ] Demande en cours : construire et vérifier les quatre écrans de suivi avec données privées par bébé
- [ ] Bibliothèque de 60+ aliments (Santé publique France), statuts par bébé
- [ ] Journal : déjeuner (plat, dessert), goûter, ingrédients, autocomplétion
- [ ] Observations peau/selles, « Aucune réaction observée », alerte 15/112
- [ ] Tableau de bord (KPI, jauge d'exploration) + calendrier/historique

## Phase 3 — Engagement
- [ ] Invitations familiales par e-mail + rôles + révocation
- [ ] Photos (stockage privé), rappels in-app, push web si supporté
- [ ] PWA installable (manifeste, sans cache des données de santé)

## Phase 4 — Monétisation & vie privée
- [ ] Annonceurs, campagnes, créations, emplacements contextuels, rapports agrégés
- [ ] Consentements, export et suppression de compte

## Décisions ouvertes (revue humaine)
- Conformité RGPD et éventuel hébergement HDS avant lancement commercial
- Validation des fiches aliments par un professionnel de santé
